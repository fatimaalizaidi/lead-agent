# Onboarding and WhatsApp Setup

ReplyHub is a demo company; these steps are fictional but follow the usual WhatsApp Business API flow.

Most teams go live in **1–3 days** on Starter and Growth. Enterprise onboarding takes **1–2 weeks**, mainly for SSO, API and data migration.

## What you need before you start
- A **Meta Business account** (business.facebook.com)
- A phone number that can receive an SMS or call for verification and is **not** already used in the WhatsApp or WhatsApp Business app (or one you are ready to move)
- Your business name, address and website for Meta's business verification

## Setup steps
1. Sign up for ReplyHub and choose a plan (or start the 14-day free trial).
2. Click **Connect WhatsApp** and log in with your Meta Business account (embedded signup).
3. Add and verify the phone number with the code Meta sends.
4. Set the display name; Meta reviews it, usually within 24–48 hours.
5. Invite agents by email; each accepted invite uses one agent seat.
6. Set up auto-assign rules, tags and quick replies (Growth and Enterprise).
7. Send a test message, then share the number with customers.

## Chat history
Chats from the regular WhatsApp Business app on a phone **cannot be imported**. History in ReplyHub starts from the day the number is connected.

## Enterprise extras
- A Customer Success Manager runs a kickoff call and a pilot with 3–5 agents
- SSO (SAML) setup and API keys for your developers
- Contacts can be imported from CSV
