What happens when you click

What the production API does with every lead the n8n workflow sends it. On this page GPT always runs as well, so you can compare the two models.

1 · Guardrails

Input checks

Length limits and prompt-injection detection. Try the 🛡️ example.

2 · Route

LoRA classifier first

A confident Low (spam, no buying intent) is answered here in ms, for free. GPT is never called.

3 · Retrieve

Hybrid RAG

Everything else: vector search + BM25 keyword search, fused with Reciprocal Rank Fusion.

4 · Reason

GPT-4o-mini

Strict JSON schema output: priority, reply, rationale, sources.

5 · Remember

Redis memory

Follow-ups in the same thread see the earlier turns.
